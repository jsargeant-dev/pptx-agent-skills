# Logo Rules

## Approved Logo Assets

Use the full horizontal West Monroe logo for all brand placements except favicons.

Approved horizontal logos:

- `assets/logo/wm_h_pos_clr_rgb_august2024.svg`
- `assets/logo/wm_h_pos_clr_rgb_august2024.png`
- `assets/logo/wm_h_rev_wht_rgb_august2024.svg`
- `assets/logo/wm_h_rev_wht_rgb_august2024.png`

Approved favicon-only compass assets:

- `assets/logo/wm_compass_pos_clr_rgb_august2024.svg`
- `assets/logo/wm_compass_pos_clr_rgb_august2024.png`
- `assets/logo/wm_compass_rev_wht_rgb_august2024.svg`
- `assets/logo/wm_compass_rev_wht_rgb_august2024.png`

## Usage Rules

- Use the full horizontal logo everywhere except the favicon.
- Use the compass logo only as a favicon.
- Use the Grounded Blue logo on light backgrounds.
- Use the white logo on dark backgrounds.
- Prefer SVG for web use. Use PNG only when SVG is not supported.

## Background Selection

- Canvas Gray `#F8F8F8`: use Grounded Blue logo.
- White `#FFFFFF`: use Grounded Blue logo.
- Mist / light gray `#E8EEF8`: use Grounded Blue logo.
- Medium gray `#CED7E6`: use Grounded Blue logo.
- Grounded Blue `#070154`: use white logo.
- Dark gray `#50658E`: use white logo.

## Size and Clear Space

- Minimum symbol height on screen: `24px`.
- Clear space: `0.5x` the logo height on every side.
- Example: if logo symbol height is `24px`, keep at least `12px` clear space on each side.

## Do Not

- Do not recolor the logo.
- Do not stretch the logo.
- Do not crop the logo.
- Do not add shadows or effects.
- Do not place the logo over busy imagery.
- Do not use the compass mark as a standalone brand mark outside favicon contexts.
- Do not recreate the wordmark with live text.

## LLM Instruction

When generating West Monroe demos, use the full horizontal logo asset. Select the Grounded Blue version for light surfaces and the white version for dark surfaces. Use the compass asset only for favicons, browser icons, or app icon metadata.
