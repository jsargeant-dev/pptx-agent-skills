# Validation Checklist

Use this checklist before shipping a West Monroe-branded demo.

## Required

- IBM Plex Sans is used for headings, headlines, display type, subheads, large statistics, and eyebrows.
- Arial is used for body copy, navigation, buttons, labels, controls, and captions.
- IBM Plex Sans is loaded from the documented Google Fonts URL or an approved self-hosted equivalent.
- No gradients are used.
- No shadows are used.
- Default corner radius for layout surfaces is `0`.
- Buttons and search fields use the approved rounded component treatment when those controls appear.
- Rounded corners outside approved buttons/search fields appear only where an approved component explicitly requires them.
- Canvas Gray `#F8F8F8` is the default page background.
- White is used for content surfaces, controls, and inverse text.
- Grounded Blue is used for primary text, structure, controls, and dark sections.
- Accent colors are used sparingly.
- Text/background combinations follow WCAG 2.0 AA rules from `color-spec.json`.
- The full horizontal logo is used for brand placements.
- The compass mark is used only as a favicon.
- Logos are not recolored, stretched, cropped, shadowed, or placed over busy imagery.
- Data visualization uses only the documented palettes and sequence rules.
- Graphic assets are used only when they support content, not as required hero treatments.
- Voice and copy guidance are not inferred from this guideline package.

## File Checks

- `brand/brand-spec.json` is accessible directly.
- `brand/tokens.json` is accessible directly.
- `brand/tokens.css` is accessible directly.
- `brand/llm-instructions.md` is accessible directly.
- `brand/component-spec.json` is accessible directly.
- `assets/asset-manifest.json` is accessible directly.
- Logo SVG assets are accessible directly.
